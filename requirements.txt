# Wedding Face Finder — Stage 1 + Stage 2 (local scripts, week 1-2)
#
# Deliberately NOT depending on the `insightface` package. We load the ONNX
# weights directly and implement SCRFD decoding / 5-point alignment ourselves
# (wff/process/detect.py, wff/process/align.py). Three reasons:
#   1. insightface has no prebuilt wheel for CPython 3.12 on Windows; it needs
#      an MSVC toolchain to build its Cython extension.
#   2. We need to drive the detector tile-by-tile at native resolution, which
#      its FaceAnalysis wrapper does not expose.
#   3. Landmine #1 in docs/ARCHITECTURE.md — the pretrained weights are
#      non-commercial. Keeping the model behind our own Detector/Embedder
#      interfaces makes swapping them a one-file change.
